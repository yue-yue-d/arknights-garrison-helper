# 卫戍协议助手（卫戍协议·规程 悬浮窗）

像 HDT 那样贴在游戏左边的悬浮窗：在当前地图上实时规划阵容，随时查规程资料（带 PRTS 配图）。

**双击 `卫戍协议助手.lnk` 启动**（或 `程序\WeishuHelper.exe`）。右下角托盘会出现一个绿色「卫」图标。

> 安全说明：这是**外置悬浮窗**，只读取游戏窗口的位置和大小来贴靠，**不读写游戏内存、不注入、不改游戏文件**。明日方舟装有 ACE 反作弊，所以没有做 HDT 那种读游戏内存的功能——地图和阵容都需要手动选。

---

## 快捷键（全局）

| 按键 | 作用 |
|---|---|
| `Ctrl+Shift+F1` | 显示 / 隐藏 |
| `Ctrl+Shift+F2` | 鼠标穿透（同标题栏的「穿透」按钮） |
| `Ctrl+Shift+F3` | 切换 布阵 ⇄ 资料 |

也可以点托盘图标显示 / 隐藏，右键托盘图标退出。

## 位置和外观

- 默认**贴在游戏画面左侧里面**，游戏窗口移动、缩放时自动跟着走。
- **只在游戏在最前面时显示**（切到别的程序自动藏起来）；游戏没开时一直显示，方便提前规划。
- 圆角面板。拖标题栏调整位置；右下角小三角拖宽、拖高。
- **收起**：点 `◀` 或双击标题栏，悬浮窗缩成一个圆形**悬浮球**（图片 + 主题色光圈）。按住拖动可以放到屏幕任何地方（位置会记住），**单击**展开回原来的位置。
- **贴边隐藏**：把悬浮球拖到屏幕边缘（上下左右都行）松手，它会贴住边缘、藏进去一半并变成半透明；鼠标移上去会整个滑出来，移开又藏回去。设置里可以关掉。
- **鼠标穿透**：点标题栏的「穿透」，鼠标操作直接穿过悬浮窗给游戏；这时只有「穿透」按钮本身还能点（收起时是小球），**再点一次就恢复**。
- ⚙ 设置里可以改：
  - **外观**：主题色、面板底色、悬浮球光圈颜色（各有 8 个预设色，「自定义…」打开系统取色器选任意颜色；光圈默认跟随主题色），改了立刻生效。
  - **悬浮球图片**：规程联合成就奖杯 1～8 级（默认 8 级金色）、卫戍节点、任意干员头像，或「选择图片文件…」用自己的图（会复制到 `数据\图片\自定义\`）。还能调悬浮球大小。
  - 「恢复默认外观」一键还原配色和悬浮球。
  - **显示**：宽度、不透明度、字号，是否只在游戏在前台时显示，部署顺序。
- 游戏要用**窗口化或无边框全屏**。独占全屏时悬浮窗可能盖不上去。

## 页签

### 攻略（暂时下线）
攻略页先从界面上拿掉了，以后再更新。之前的内容都还在：`攻略\通用攻略.md` 和代码（`src\Views.cs` 的 GuideView）。恢复方法：把 `src\OverlayWindow.xaml.cs` 里的 `GuideEnabled` 改成 `true`，再去掉 `OverlayWindow.xaml` 里 TabGuide 的 `Visibility="Collapsed"`，重新编译。

原来的功能：
- 下拉框选「本图攻略」：显示布阵页当前选的战场的 PRTS 信息（出现难度、装置、特殊地形），下面接你自己写的 `攻略\地图\#01.md`。
- 也可以选 `攻略\` 文件夹里的任何 `.md` 文件，例如 `通用攻略.md`（规程的规则整理）。
- 点「编辑」用记事本打开，**保存后悬浮窗立刻刷新**。支持 `#` 标题、`-` 列表、`>` 提示框、`|` 表格、`**加粗**`、`==高亮==`，写 `【炎】` 这类盟约名会自动着色。

### 布阵
1. 选战场（#01–#12）。**布阵区的底图是这张图的 PRTS 截图（场地2）**，格子是透明的、藏在图片里。
2. **第一次用某张图时，点「编辑地形」标记格子**（每张图做一次，这张图所有方案共用）：
   1. 网格已经按截图对好了（三种场景各量了一次：沙漠和城市 #01–#06 是 11×4，雪地 #09 #11 是 12×4，教堂 #10 #12 是 11×4；最右边一列有一部分在截图外面）。
   2. 选 **地面 / 高台 / 不可部署**（或 敌人入口、保护点、特殊地块），点格子标记；按住左键可以连续涂，右键擦掉。
   3. 万一没对准：选「**对齐网格**」拖四个黄色圆点微调，「列± / 行±」改格子数，「恢复默认网格」回到初始位置。默认值在 `数据\网格默认.json`。
   - 退出「编辑地形」后格子又变回透明。想看自己标了什么，点「**显示格子**」。
   - 拿起干员时，能放的已标记格子会微微发亮（近战干员不会在高台上亮）。
   - 没标记的格子什么都能放，标记完再用就有限制了。
3. 在下面的干员列表里**点一下拿起干员，再点格子放下**；点 `＋` 放进整备区。
   - 格子、整备区、干员列表里都是**干员头像**（边框 = 等阶颜色，左上角 = 部署顺序，右上角 ★ = 精锐）。鼠标移到头像上会盖一层半透明黑底显示名字，停久一点出现详细说明。
   - 点场上的干员可以拿起来换位置；拿着干员点整备区 = 放回整备区；右键空格或 Esc 取消。
   - 右键干员：设为精锐 ★ / 放回整备区 / 移除 / 在资料页查看。
   - 会拦住：超过部署上限 8 人、近战放高台、放到不可部署的格子。
4. 自动计算：
   - **盟约**：`炎 4/6` = 现在 4 人，下一档要 6 人；绿色 = 已激活，金色 = 强化，灰色 = 还差人。鼠标停上去看效果和还缺哪些成员，点一下只看这个盟约的干员。
   - 【远见】【奇迹】【投资人】会把整备区算进去；【调和】给核心盟约 +1；【独行】只有 1 人时生效；【绝技】数精锐人数。
   - **部署顺序**：格子左上角的数字（游戏内是「从左至右、从上到下」，默认先按列；不对的话在设置里改成先按行）。
5. 「本局可用盟约」：开局时把这局没有的盟约点灰，干员列表只剩这局能拿到的人。
6. **支援（甄选）**：干员列表上方「干员」右边的「**支援**」页签。规程第Ⅴ、Ⅵ阶各有 **2 个甄选槽位**，可以放：
   - **名单外的所有 6★ 干员**（本期内置的 6★ 不在这里）；
   - **精英干员**：罗德岛特派高级资深干员（Pith、Sharp、Stormeye、Touch、Misery、Mechanist、Raidian、领主·Sharp、郁金香，即Ⅳ～Ⅵ阶的原型干员）。
   - 每行的「Ⅴ」「Ⅵ」= 放进整备区并占用那一阶的甄选槽位；点整行直接拿起（优先放Ⅵ阶）。槽位满了按钮会变灰，上方显示「Ⅴ阶 x/2　Ⅵ阶 x/2」。同一个干员只能放在一阶，多拿几份（三合一）不额外占槽位；右键可以改到另一阶。
   - 盟约按 PRTS 的「所属国家」给核心盟约（如 炎-龙门 →【炎】、维多利亚 →【维多利亚】），本期没有对应核心盟约的（罗德岛、哥伦比亚、东国等）给【协防干员】。**甄选干员没有特质**。
   - 布阵里甄选干员的头像边框是所在阶的颜色，右下角有「甄」字。
   - 名单来自 PRTS（`数据\支援.json`），「更新数据」时会一起刷新；新出的 6★ 也会自动加进来。
7. 每张图可以存多个方案（新建 / 复制 / 改名 / 删除），选的策略和备注一起保存，改动自动存盘。

### 资料
规程的 干员（143）/ 盟约（26）/ 策略（61）/ 装备（70）/ 机变阶段（142）/ 领袖（10）/ 地图（10），都能搜索。点干员卡片上的盟约会跳到那个盟约。

- **干员 · 快速检索**（点「快速检索 ▴」收起 / 展开）：按阶级（Ⅰ～Ⅵ，可多选）和盟约（核心、附加，可多选）筛选。选了两个以上盟约时，可以选「有其中任一个」或「同时都有」。「清除」一键清空。
- **装备**：按阶级筛选（Ⅰ～Ⅵ，按钮上是件数）。

**配图**（全部从 PRTS 下载，存在 `数据\图片\`，共 447 张）：

| 分类 | 配的图 |
|---|---|
| 干员 | 头像（边框是等阶颜色）；盟约标签带盟约图标 |
| 盟约 | 盟约图标 + 所有成员头像（鼠标停在头像上看是谁） |
| 策略 | 策略发起人头像（PRTS 上规程沿用盟约赛季的发起人图） |
| 装备 | 装备图标 |
| 机变 | 悬赏类：被加进战场的敌人头像；盟誓：那名干员的头像；驰援：对应盟约图标；财富：资金图标 |
| 领袖 | 敌人头像；卡片上点「个人模拟血量 ▾」展开极速模拟、规程等级1～20 的血量 |
| 地图 | 场地2 的截图（和布阵页底图是同一张），鼠标停上去看大图 |

机变阶段里有 9 项（列装、补给、整备、升华、自愈、火力、征召、无瑕、锐利）**PRTS 上没有配图**，显示的是名字首字的占位方块。

**机变阶段子分类**：第一行是 PRTS 的两大组，第二行是细分（细分是按选项名字归的类）：
- 敌人轮选：单只悬赏 / 多轮悬赏 / 特训 / 飞行·频次·损伤·持续·隐匿·折射·特异 悬赏
- 联合增益/减益：盟誓 / 驰援 / 资源 / 战斗效果

## 更新数据（序列Ⅱ / 新赛季）

⚙ 设置 →「从 PRTS 更新数据」→ 跑完后点「重新载入数据」。或者手动运行：

```bash
python -X utf8 "C:\AI项目\卫戍协议助手\工具\更新数据.py"
```

脚本里的 `SEASON = "卫戍协议·规程"` 决定读哪个赛季的 PRTS 页面；以后换赛季改这一行。

## 修改程序后重新编译

```bash
dotnet publish "C:\AI项目\卫戍协议助手\src" -c Release -o "C:\AI项目\卫戍协议助手\程序" --self-contained false
```

（先退出正在运行的悬浮窗。）

## 绿色版（发给别人用）

成品在 `发布\`：
- `卫戍协议助手_v1.1.0_绿色版_win-x64.zip`：解压即用，自带 .NET 运行时，别的电脑不用装任何东西（Windows 10/11 64 位）。
- `发布\卫戍协议助手\` 是同一份内容的文件夹。里面没有你的 `设置.json` 和 `布阵\` 方案。
- 程序是单文件 exe（约 59 MB），旁边 5 个 `*_cor3.dll` 是 WPF 的显示组件。这样运行时不会往 `%TEMP%` 或 AppData 写东西，删文件夹就是卸载。

重新打包（改了代码或更新了数据以后）：

```bash
dotnet publish "C:\AI项目\卫戍协议助手\src" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o "C:\AI项目\卫戍协议助手\发布\_build"
```

然后把 `_build\WeishuHelper.exe` 改名为 `卫戍协议助手.exe`，和 `*_cor3.dll`、`数据\`、`攻略\`、`工具\更新数据.py`、`发布\使用说明.txt`、一个空的 `布阵\` 放进同一个文件夹再压缩。压缩时要用 UTF-8 文件名（Python `zipfile` 默认就是），中文名才不会乱码。

## 安卓版

成品：`发布\卫戍协议助手_v1.1.0_安卓版.apk`（约 42 MB，Android 8.0 及以上）。传到手机上点开安装即可（手机会提示“允许安装未知来源应用”）。

用法：
1. 打开「卫戍协议助手」，点右上「去授权」，在系统设置里打开「显示在其他应用上层」，回来点「开启悬浮窗」。
2. 屏幕边上会出现奖杯悬浮球。切到明日方舟，点悬浮球展开面板（布阵 / 资料 / ⚙ 设置，和电脑版一样）。
3. 标题栏可以拖动面板；「穿透」让手指直接点到游戏上（左上角出现「穿透中 · 点这里取消」）；「◀」收回悬浮球；「✕」关闭。
4. 悬浮球拖到屏幕边缘会半隐藏、变半透明。通知栏里有常驻通知，也可以从那里关闭悬浮窗。
5. 搜索框只有点它时才会弹出键盘，平时悬浮窗不抢游戏的焦点；打字时面板自动收起标题栏给键盘让地方。

不打游戏时也可以直接在 App 里查资料、排布阵（和悬浮窗是同一份数据）。布阵存档格式和电脑版相同（`布阵/#01.json`），存在 App 的私有目录里。

源码在 `android\`（Kotlin + Jetpack Compose）。数据和图片在打包时直接从上面的 `数据\` 文件夹拷进 APK，所以 `工具\更新数据.py` 更新数据后重新打包就行：

```bash
cd "C:\AI项目\卫戍协议助手\android"
gradlew.bat assembleRelease
```

- 需要 JDK 17（`C:\Program Files\Java\jdk-17.0.1`）和 Android SDK（`C:\Android\sdk`，路径写在 `android\local.properties`）。本机下载依赖要走代理，命令后面加 `-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7897`。
- 输出在 `android\app\build\outputs\apk\release\app-release.apk`。
- 发布签名在 `android\签名\`（自动生成的密钥）。**请备份这个文件夹**：以后的新版本必须用同一个签名，手机上才能直接覆盖安装、保留存档。
- 测试用的模拟器：`C:\Android\sdk\emulator\emulator.exe -avd weishu`（Android 15，横屏 2400×1080）。

注意：模拟器上已经测过悬浮球、展开 / 收起、穿透、贴边、转屏、布阵放干员和盟约计数、资料搜索和键盘；**还没在真机 + 真的明日方舟上试过**。有的手机系统（MIUI、ColorOS 等）还要在「应用管理」里额外允许「悬浮窗」和「后台运行」。
